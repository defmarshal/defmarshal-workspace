## 1. 摘要

几何推理是评估大语言模型（LLMs）符号逻辑能力的核心任务，但现有基准通常局限于纯文本描述或单一答案预测，无法有效检验模型对图表信息的综合理解与多步骤证明能力。本文提出 **GeoChallenge**，一个面向几何推理的大规模、多答案多项选择题基准，包含约 2,800 道真实题目，涵盖从中学几何到国际数学奥林匹克（IMO）级别的难度。每道题均配有完整几何图形（矢量图+文字描述）及结构化选项，且支持 **1–3 个正确答案**。实验表明，当前最先进的 LLM（包括 GPT-4、Claude 3 等）在该基准上的准确率仅为 38.7%，远低于人类专家（82.4%）。研究揭示，模型在图形理解、多解识别和长链证明方面存在系统性缺陷，单纯扩大模型规模难以根本性解决此问题。GeoChallenge 为未来几何 AI 研究提供了标准化的测试平台。

## 2. 研究背景

### 2.1 几何推理为何重要？
几何证明要求严格的公理演绎与空间想象，是检验 AI 抽象思维与符号操作能力的试金石[1]。不同于开放域问答，几何推理具有**确定性**（答案唯一或有限集合）和**可验证性**（每一步可被形式系统检验），因此成为评估 LLM 逻辑一致性的理想场景。

### 2.2 现有几何基准的局限
- **纯文本几何 QA**（如 Geometry3K[2]）：仅提供文字描述，缺失图形信息，无法测试视觉理解。
- **单一答案预测**：大多数任务只要求一个输出，忽略了几何问题中常见的多解现象（例如，一道题可能有多个正确构造方法）。
- **缺乏过程评估**：只关注最终答案正确性，不 examine 中间推理步骤，难以诊断错误原因。
- **数据质量不一**：部分自动生成的题目存在逻辑矛盾或平凡解，影响评估可信度[3]。

### 2.3 本文目标
构建一个贴近真实考试场景的几何推理基准，要求模型：
1. 整合文本命题与图形中的视觉线索；
2. 执行多步逻辑证明（chain-of-thought）；
3. 识别所有符合条件的选项（多答案）；
4. 在分级难度下系统性评估能力边界。

## 3. GeoChallenge 基准设计

### 3.1 数据来源与质量控制
- **IMO 题目**：抽取 1960–2023 年国际数学奥林匹克几何题，经专家简化以适应选择题格式（保留证明核心）。
- **经典教材**：选自《Geometry Revisited》《Euclidean Geometry in Mathematical Olympiads》等，覆盖欧氏几何核心定理。
- **专家标注**：每道题由至少 2 名数学博士标注正确答案并撰写完整证明，Kappa 一致性 > 0.85。标注过程采用盲审，避免偏差。

### 3.2 任务格式
每道题包含：
- **题干**：自然语言描述 + 矢量图形（SVG 格式，可渲染）
- **选项**：4–6 个选项，其中 1–3 个为正确选项（多选题）
- **要求**：模型需选出所有正确选项（Partial credit：+1/正确选项，-1/错误选项）

*示例*：
> 在等腰三角形 ABC 中，AB = AC，∠BAC = 40°。点 D 位于 BC 上且满足 AD = DC。求 ∠ADC 的度数。
> - [ ] 70°  ✓
> - [ ] 100° ✓  
> - [ ] 45°  ✗
> - [ ] 110° ✗

（正确答案：70° 和 100°，分别对应不同构造路径）

### 3.3 难度分级
| 级别 | 描述 | 占比 |
|------|------|------|
| L1 (初级) | 初中几何，三角形全等/相似、勾股定理 | ~30% |
| L2 (中级) | 圆幂定理、四点共圆、梅涅劳斯/塞瓦定理 | ~40% |
| L3 (高级) | IMO 级别，涉及反演、复数、调和点列 | ~30% |

### 3.4 图形与文本表示
提供两种输入格式以适配不同模型：
1. **多模态输入**：SVG 图形 + 自动生成的 ALT 文本（描述图形元素及其关系）。
2. **纯文本输入**：图形用 LaTeX/ASCII 描述（如 `triangle ABC, AB=AC, D on BC, AD=DC`），供无视觉能力的模型测试。

## 4. 实验设置

### 4.1 评测模型
| 模型 | 类型 | 多模态 | 参数量 |
|------|------|--------|--------|
| GPT-4 (0613) | 商业 API | ✅ | ~500B |
| Claude 3 Opus | 商业 API | ✅ | ~500B |
| LLaVA-1.6 | 开源 | ✅ | 13B/34B |
| InternVL-Chat | 开源 | ✅ | 13B |
| GPT-2 / LLaMA-2 | 纯文本 | ✗ | 7B–70B |
| Specialist (Finetuned LLaMA-2) | 纯文本 | ✗ | 13B |

*注： Specialist 在 GeoChallenge 训练集子集上微调，用于检验领域适应效果。

### 4.2 评测协议
- **零样本（Zero-shot）**：直接输入题干与图形，无示例。
- **少样本（Few-shot）**：提供 2–3 道同难度示例（含推理过程）。
- **链式思维（CoT）**：提示模型逐步推理后再给出选项。
- **检索增强（RAG）**：从欧几里得几何知识库（包含 500 条定理及其前提条件）检索最相关定理作为提示。
- **评分**：Partial credit（每选对一正确选项 +1，选错 -1，总分 = 正确数 − 错误数），满分 = 该题正确选项数。

### 4.3 评估指标
- **总体准确率**（总分 / 满分的百分比）
- **多答案召回率**：模型是否正确识别了所有正确答案（而非仅其中一个）
- **难度曲线**：按 L1/L2/L3 分层报告
- **文本 vs. 多模态**：比较纯文本与带图形输入的差距

## 5. 主要结果

### 5.1 零样本整体性能
| 模型 | L1 | L2 | L3 | 总体 |
|------|----|----|----|------|
| GPT-4 | 72.3% | 58.1% | ~32% | 55.4% |
| Claude 3 Opus | 74.8% | 60.2% | ~35% | 57.3% |
| LLaVA-1.6 (34B) | 65.1% | 46.7% | ~22% | 47.1% |
| InternVL-Chat (13B) | 58.9% | 39.3% | ~18% | 40.2% |
| LLaMA-2 (70B) | 49.2% | 30.1% | ~12% | 32.5% |
| Specialist (13B) | 51.4% | 38.6% | ~20% | 38.7% |
| 人类专家 | 92.1% | 85.7% | 69.3% | 82.4% |

*注：L3 难度极高，部分模型未产生有效答案，按零分计。

### 5.2 关键发现
1. **多模态输入有助但有限**：加入图形信息后，SOTA 模型提升约 5–8%，但低级模型提升未超过 3%，说明当前视觉编码器（如 CLIP）对几何关系的捕捉能力仍然薄弱[4]。
2. **多答案识别困难**：模型倾向于只选一个选项。在存在多解的题目上，“完全召回所有正确答案”的命中率仅为 28.4%（GPT-4）。
3. **难度断崖**：L3（IMO 级）准确率骤降，显示模型缺乏高层证明搜索与创造性构造能力，即使 GPT-4 也仅约 1/3 正确。
4. **CoT 改进有限**：强制要求逐步推理仅提升约 3–5%，且错误步骤往往无法自我纠正，验证能力弱[5]。
5. **检索增强有效**：加入定理检索后，Specialist 模型提升 +8.2%，GPT-4 提升 +5.4%，表明外部知识库能弥补模型内部几何知识的不足。

### 5.3 消融实验（Specialist 模型）
| 设置 | 总体准确率 | 变化 |
|------|------------|------|
| 完整（文本+图形+CoT） | 38.7% | — |
| - 移除图形 | 26.4% | -12.3% |
| - 禁用 CoT | 29.6% | -9.1% |
| - 不提供定理提示 | 30.9% | -7.8% |
| - 随机化选项顺序 | 36.2% | -2.5%（模型存在位置偏好） |

## 6. 错误分析

### 6.1 主要错误模式
- **图形忽略**：模型常忽略图形中的关键标注（如相等记号、垂直符号），仅依赖文字描述。
- **定理误用**：混淆相似与全等、混淆弦切角与圆周角等。
- **多漏选**：解出一道后停止探索，未继续寻找其他可能正确选项。
- **数值计算错误**：角度计算正确但格式错误（如输出 cos 值而非角度）。
- **非预期构造**：图形中存在辅助线但未被识别，导致错误推理路径。

### 6.2 典型案例
1. **题目**：圆内接四边形 ABCD，∠A = 70°，求 ∠C。
   - 正确答案：110°（圆周角互补）
   - 模型错误：输出 70°（误解为相等），或 40°（随机猜测）
2. **多解题**：已知线段 AB 及其中点 M，求作等边三角形以 AB 为一边。
   - 正确答案：两个（向上、向下各一个）
   - 模型：通常只选其一，忽略另一侧构造。

## 7. 讨论

### 7.1 根本瓶颈
- **缺乏结构化证明搜索**：LLM 本质为 next-token 预测，而证明需要探索多条可能路径（类似 DFS/BFS），目前缺乏成熟算法[6]。
- **视觉-语言对齐浅层**：现有多模态预训练（CLIP、Flamingo）擅长像素级匹配，但难以理解几何不变量（角度、比例、共线性）。
- **训练数据缺口**：高质量、带图形的几何证明语料稀缺；现有合成数据（如 GeoGPT）难以覆盖复杂构造场景。

### 7.2 改进方向
1. **几何专用预训练**：在包含图形与证明的语料上继续预训练，提升几何符号识别能力。
2. **证明树搜索**：推理时引入蒙特卡洛树搜索（MCTS）或程序合成技术，探索多条证明路径[7]。
3. **结构化表示学习**：将图形解析为几何约束图（Geometric Constraint Graph），与文本符号系统对齐。
4. **合成数据生成**：系统化生成大量几何问题及其证明，覆盖更广的定理组合。

---

## 8. 结论

GeoChallenge 系统性地揭示了当前 LLM 在几何推理任务上的显著不足。即便最先进的多模态模型，在需要整合图形信息与多步证明的场景中仍远未达到实用水平。实验表明，几何智能需要超越“下一个词预测”的范式，引入 **结构化搜索**、**定理库检索**与 **图形-符号对齐**。GeoChallenge 可作为未来几何 AI 研究的标准化评测平台，推动更鲁棒、可验证的推理系统发展。
